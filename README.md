**PromptCraft AI**

PromptCraft AI is an educational Prompt Engineering application that demonstrates different prompting techniques and shows how the structure of a prompt can influence the response generated by an AI language model.

The application provides an interactive interface where users can select a prompting technique, enter a task, generate the corresponding prompt, and view the resulting response.

## Features

* Interactive Streamlit-based web interface
* Demonstrates multiple Prompt Engineering techniques
* Displays the generated prompt before generating the response
* Adjustable temperature
* Adjustable maximum token limit
* AI-generated responses using a language model
* Simple and user-friendly interface
* Suitable for learning, experimentation, and academic demonstrations

## Prompting Techniques

### 1. Zero-Shot Prompting

Zero-shot prompting asks the AI model to perform a task without providing any examples.

Example:

```text
Task:
Explain Artificial Intelligence.
```

The model understands the task based only on the instruction provided.

### 2. One-Shot Prompting

One-shot prompting provides one example to demonstrate the expected type or style of answer.

Example:

```text
Example:
Task: Explain Python.
Answer: Python is a high-level programming language.

Task:
Explain Java.
```

The model uses the example as a reference when generating the answer.

### 3. Few-Shot Prompting

Few-shot prompting provides multiple examples before asking the model to perform a new task.

Example:

```text
Example 1:
Task: What is AI?
Answer: AI enables machines to perform intelligent tasks.

Example 2:
Task: What is ML?
Answer: ML enables systems to learn patterns from data.

Task:
What is Deep Learning?
```

Multiple examples help the model understand the expected pattern.

### 4. Chain-of-Thought Prompting

Chain-of-Thought prompting encourages the model to approach a problem through logical steps before producing the final answer.

For safety and clarity, the application displays only a concise explanation of important steps rather than private internal reasoning.

### 5. Manual Chain-of-Thought

Manual CoT provides an explicit reasoning structure for the model.

The application uses steps such as:

```text
Step 1 - Understand the task
Step 2 - Identify important information
Step 3 - Apply the appropriate method
Step 4 - Verify the result
Step 5 - Provide the final answer
```

This makes the reasoning structure clear and consistent.

### 6. Tree-of-Thought Prompting

Tree-of-Thought prompting explores multiple possible approaches to solve a task.

The application provides:

```text
Approach A
Approach B
Approach C
Selection
Final Answer
```

The possible approaches are compared and the most suitable approach is selected.

## File Description

### app.py

Contains the Streamlit user interface.

It handles:

* Prompting technique selection
* Task input
* Temperature selection
* Maximum token selection
* Prompt generation
* Response display

### llm.py

Handles communication with the language model through the Hugging Face Inference API.

It also loads the API token securely from the `.env` file.

### prompt_templates.py

Contains the prompt templates for all six prompting techniques.

It converts the selected technique and user task into the appropriate prompt.

### requirements.txt

Contains the Python packages required to run the application.

## Installation

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

### Step 2: Open the Project

```bash
cd "PromptCraft AI"
```

### Step 3: Install Dependencies

```bash
py -m pip install -r requirements.txt
```

### Step 4: Configure API Token

Create a `.env` file in the project folder.

```env
HF_TOKEN=your_huggingface_token_here
```

Do not share your API token publicly.

### Step 5: Run the Application

```bash
py -m streamlit run app.py
```

The application will open in your browser.

API credentials should never be directly written inside Python source code.

Use a `.env` file to store sensitive credentials and add `.env` to `.gitignore`.

Example:

```text
.env
__pycache__/
```
